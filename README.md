# Система бронирования гостиничных номеров

Задание по дисцеплине "Объектно-ориентированное программирование"

Реализация системы бронирования с использованием паттернов **Фабрика** и **Наблюдатель**.

## Возможности

- Создание номеров разных типов через фабрику (стандарт, делюкс, люкс)
- Бронирование номеров на выбранные даты
- Отмена бронирования
- Уведомления наблюдателей о событиях (новое бронирование / освобождение номера)

## СТРУКТУРА ПРОЕКТА

- 'src/hotel.py' - исходный код
- 'diagrams/hotel_UML.jpg' - UML-диаграмма классов

## Запуск

```bash
cd src
python hotel.py
```
